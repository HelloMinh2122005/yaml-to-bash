# y2 Squad Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the self-contained Claude (plan) + Antigravity (build) squad for `yaml_to_bash`, including the lab guard that lets Antigravity run real-Azure tests safely.

**Architecture:** Safety rails first as small, tested Python/Bash units under `lab/` and the two hook dirs (lab identity → `az` shim → lab runner → write/command guards). Then the prose layer (protocol, 4 Claude agents + 3 skills, Antigravity plugin with 7 agents + skills + vendored skills), pinned by a manifest test. Everything is tested with pytest; nothing in this plan calls real Azure.

**Tech Stack:** Python 3 stdlib (3.9-compatible), Bash (3.2-tolerant), pytest, Claude Code agents/skills/hooks, Antigravity `.agents/plugins/` format (as used in `~/Downloads/Occupify/.agents/plugins/ai/`).

**Spec:** `docs/superpowers/specs/2026-10-31-y2-squad-design.md` — read it alongside this plan; section numbers below (§n) refer to it.

## Global Constraints

- Python: stdlib only, Python 3.9 compatible — no `match`, no `X | Y` outside annotations, no `zip(strict=)`, no `dataclass(slots=/kw_only=)`; add `from __future__ import annotations` where hints use `list[str]` / `Optional`.
- Bash: must run under bash 3.2 — no associative arrays, no `mapfile`/`readarray`, no `${var,,}`.
- Never call real Azure in tests: every test puts a stub `az` first on `PATH` or sets `Y2_REAL_AZ` to a stub.
- Never read or print `lab/terraform.tfvars`, `*.tfstate*`, `lab/.terraform/**`, `~/.config/y2-lab/**`.
- Lab identity values (copy exactly): subscription `79f7da80-0c64-4e4b-9ed4-316a88142152`, RG `rg-lab-10vms`, VMs `lin01 lin02 lin03 win01 win02`; forbidden RG `rg-tfstate`.
- Models (copy exactly): `y2-lead` → `model: claude-opus-5-5`, `effort: high`; `y2-planner` and `y2-test-planner` → `claude-sonnet-5-5`, `high`; `y2-research-planner` → `claude-sonnet-5-5`, `medium`; all 7 Antigravity agents → `model: flash`, `subagent: true`, body line `**Reasoning Effort Profile: HIGH** — Gemini 3.8 Flash at High thinking.`
- agent-chat addresses: `claude-code/y2-lead` ⇄ `antigravity/y2-tech-lead`. No other agent uses agent-chat.
- Existing repo tests and both goldens (`tests/golden/*`) must stay unchanged and green.
- Work happens in a git worktree on branch `feat/y2-squad`; the owner's uncommitted v4 work in the main tree is never touched.

## Review Focus

1. **An Antigravity agent edits the guard itself** (`lab/az-shim/az`, `lab/run-lab.sh`, `lab/lab.env`, `lab/*.py`, the plugin's `scripts/` or `hooks.json`) → must be denied, or every other layer is moot. Pinned in Task 5 (`test_protect_denies_guard_files`).
2. **`y2b run` / `y2p run` launched directly** by an Antigravity agent instead of through `lab/run-lab.sh` → would hit Azure with whatever login is on the machine. Pinned in Task 5 (`test_lab_guard_denies_direct_y2_run`).
3. **Legitimate `az` forms the shim must still allow**: `--ids` lists (used by `toogle_vm.sh`), full `https://management.azure.com/...` URLs, upper-case `POST`, URL-encoded RG, `--subscription` omitted. A false deny breaks the lab runner; a sloppy parser makes a false allow. Pinned in Task 2 (`test_allow_cases`).
4. **Shim recursion / misconfig**: `Y2_REAL_AZ` unset or pointing at the shim itself → must refuse, not loop. Pinned in Task 2 (`test_shim_refuses_without_real_az`, `test_shim_refuses_self_reference`).
5. **Path traversal into code** for Claude roles (`.handoffs/x/../../y2shared/a.py`) and CSV rows with odd spacing/case (` LIN01 `, upper-case GUID). Pinned in Task 4 (`test_traversal_denied`) and Task 1 (`test_validate_csv_normalises`).

### Task 2: `az` shim (`lab/azpolicy.py`, `lab/az-shim/az`)

**Files:**
- Create: `lab/azpolicy.py`, `lab/az-shim/az` (executable, `#!/usr/bin/env python3`), `tests/squad/test_az_shim.py`

**Interfaces:**
- Consumes: `LabEnv`, `load_lab_env`, `is_lab_subscription` (Task 1).
- Produces:
  - `check_az_args(argv: list[str], lab: LabEnv) -> str | None` in `lab/azpolicy.py` — `None` = allow, else a one-line reason. Rules exactly as spec §8.3:
    - `account show` (any args) → allow. `account set --subscription X` → allow iff `is_lab_subscription(X)`.
    - `vm show|list|get-instance-view|start|deallocate` and `vm run-command invoke|show|list` → allow iff every target is in the lab: `-g/--resource-group` equals lab RG (case-insensitive); `-n/--name` in `lab.vms`; every `--ids` value parses as `/subscriptions/<lab-sub>/resourceGroups/<lab-rg>/providers/Microsoft.Compute/virtualMachines/<lab-vm>`; `--subscription` absent or `is_lab_subscription`. `vm list` needs `-g`.
    - `rest`: method from `--method/-m` (case-insensitive, default `get`); URL from `--url/--uri/-u`, strip optional `https://management.azure.com` prefix and query string, URL-decode. `get` → allow iff path starts with `/subscriptions/<lab-sub>/resourceGroups/<lab-rg>/` (case-insensitive). `post` → allow iff path is exactly `/subscriptions/<lab-sub>/resourceGroups/<lab-rg>/providers/Microsoft.Compute/virtualMachines/<lab-vm>/<action>` with `action ∈ {runCommand, start, deallocate, powerOff}`. Any other method → deny.
    - Everything else → deny. Any argv token containing `rg-tfstate` (case-insensitive) → deny regardless of command.
  - Shim `lab/az-shim/az`: loads `LabEnv` (`Y2_LAB_ENV` or `../lab.env` relative to the shim), calls `check_az_args(sys.argv[1:])`; on deny prints `y2 lab guard: refused: <reason>` to stderr, exit 3. On allow: `real = os.environ["Y2_REAL_AZ"]`; refuse (exit 3) if unset, not executable, or `os.path.realpath(real) == os.path.realpath(__file__)`; else `os.execv(real, [real] + argv)`.
